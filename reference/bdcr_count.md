# Contar registros de ocurrencia para un taxón

Contar registros de ocurrencia para un taxón

## Usage

``` r
bdcr_count(taxon)
```

## Arguments

- taxon:

  Character. Nombre científico del taxón (e.g. \`"Panthera onca"\`).

## Value

Entero con el número total de registros.

## Examples

``` r
if (FALSE) { # \dontrun{
bdcr_count("Panthera onca")
} # }
```
