# Costa Rica national boundary

An \`sf\` object with the national boundary of Costa Rica from GADM.

## Usage

``` r
cr_outline
```

## Format

An \`sf\` object with 1 row and the following columns:

- GID_0:

  Country code (CRI)

- COUNTRY:

  Country name

- geometry:

  MULTIPOLYGON geometry
